# Logos

Armazenar aqui os arquivos oficiais aprovados da Julius Bier.

Estrutura sugerida:

- `master/`: arquivos-fonte e versões vetoriais principais.
- `horizontal/`: assinatura horizontal.
- `vertical/`: assinatura vertical.
- `symbol/`: símbolo independente.
- `monochrome/`: versões de uma cor.
- `exports/`: PNGs e PDFs para uso cotidiano.

Não armazenar estudos não aprovados na pasta de arquivos oficiais.
