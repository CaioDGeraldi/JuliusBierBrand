# Adesivos

Armazenar artes finais, provas de impressão e arquivos de produção dos cinco estilos.

Organizar por estilo e manter separados:

- Arquivo-fonte editável.
- SVG ou PDF vetorial.
- PNG de visualização.
- Prova de impressão aprovada.

As dimensões e especificações de material devem acompanhar cada arte final.
