# Tipografia

Armazenar referências, licenças e arquivos de fontes utilizadas no projeto.

Antes de adotar uma fonte, registrar:

- Nome e versão.
- Família e pesos utilizados.
- Licença e permissões de uso comercial.
- Fonte substituta para ferramentas sem acesso à fonte principal.

A tipografia definitiva ainda será selecionada e aprovada.
