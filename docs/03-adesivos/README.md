# 03. Adesivos por estilo

## Objetivo

Criar um sistema de adesivos que identifique rapidamente cada cerveja e mantenha a Julius Bier como marca principal.

## Hierarquia visual obrigatória

1. Julius Bier: assinatura institucional.
2. Nome do estilo: identificação principal do produto.
3. Descrição curta: apresentação sensorial.
4. Indicadores: informações técnicas confirmadas.
5. Identificador visual: cor, número ou grafismo próprio do estilo.

## Requisitos de produção

- [ ] Definir dimensões por superfície de aplicação.
- [ ] Definir material e acabamento.
- [ ] Preparar sangria e área segura.
- [ ] Validar legibilidade em tamanho real.
- [ ] Criar versões para superfícies curvas, quando necessário.
- [ ] Exportar PDF de impressão e SVG/PNG de referência.

## Dados que não podem ser inventados

ABV, IBU, volume, lote, validade, temperatura recomendada e qualquer alegação sobre ingredientes devem vir de informações confirmadas pela cervejaria.

## Critérios de aprovação

Todos os cinco adesivos devem parecer parte da mesma família, ser identificáveis à distância e continuar legíveis quando aplicados em equipamentos ou recipientes.
