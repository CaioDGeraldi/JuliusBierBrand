1. Julius Bier em posição consistente com os demais estilos.
2. Nome do estilo com maior destaque após a marca.
3. Cor de identificação exclusiva, harmonizada com a paleta institucional.
4. Descrição curta e legível.
5. Dados técnicos somente quando fornecidos e aprovados.

## Aplicações a considerar

- Torneiras e identificadores de chopeira.
- Copos e taças.
- Barris e recipientes.
- Garrafas, latas e embalagens.
- Materiais de balcão e exposição.

Cada superfície pode exigir uma composição ou dimensão diferente. Não assumir que um único adesivo servirá para todos os suportes.
