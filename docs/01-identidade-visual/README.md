# 01. Identidade visual

[← Voltar ao início](../../README.md)

## Objetivo

Definir os elementos centrais que tornam a Julius Bier reconhecível em qualquer ponto de contato.

## Entregáveis

- [ ] Logotipo principal (wordmark).
- [ ] Símbolo independente.
- [ ] Assinatura combinada (símbolo + nome).
- [ ] Versão horizontal.
- [ ] Versão vertical.
- [ ] Versão monocromática positiva e negativa.
- [ ] Versão reduzida para avatar, tampa e pequenos espaços.
- [ ] Arquivos vetoriais finais em SVG e PDF.
- [ ] Arquivos rasterizados de apoio em PNG.

## Direção visual aprovada como ponto de partida

| Cor | HEX | Função |
|---|---|---|
| Verde Floresta | `#183D32` | Cor institucional |
| Creme Pilsen | `#F1E6CF` | Fundo e contraste |
| Dourado Malte | `#B38A4A` | Destaques e detalhes |
| Marrom Madeira | `#472D24` | Apoio |

**Conceito:** tradição em cada estilo.

A estética pode dialogar com referências históricas de cervejarias, mas não deve sugerir que todo o portfólio é alemão. A Weiss Tradicional Alemã é um estilo específico do portfólio, não o posicionamento nacional da empresa.

## Critérios de aprovação

- Reconhecimento em tamanho pequeno.
- Boa leitura em uma cor.
- Aplicação em fundos claros e escuros.
- Desenho original, sem depender de símbolos genéricos ou clichês.
- Reprodutibilidade em impressão, gravação, bordado e adesivagem.

## Arquivos

Os arquivos finais deverão ser armazenados em [assets/logos](../../../../assets/logos/README.md).
